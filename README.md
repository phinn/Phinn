# Hi, I'm Phinn 👋

Builder of the **Kinet family** — a suite of focused macOS/iOS apps, each built around a single job, all sharing the same design language: **local-first, on-device AI, no account required**.

## 🔷 KinetAios — the flagship (open source)

**[KinetAios](https://github.com/phinn/KinetAios)** · `TypeScript` · GPL-3.0 · Windows + macOS

A local-first AI agent dashboard for **Windows 11 & macOS**: multi-engine sessions (Direct / Claude Code / Codex / and more), 30+ built-in tools, 21 plugins, Plugin SDK, MCP client **and** server, SQLite long-term memory with FTS5, global hotkey. Your keys, your machine, your data.

⭐ If it's useful, a star helps a lot.
